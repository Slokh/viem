# `earn.getNestedAllocation`

Gets the live inner and outer asset split for a nested Earn deposit.

## Usage

```ts twoslash
import { client } from './viem.config'

const allocation = await client.earn.getNestedAllocation({
  assetAmount: 100_000_000n,
  outerVault: '0x0000000000000000000000000000000000000002',
  recipient: client.account.address,
})
// @log: { assetAmount: 100_000_000n, innerAssetAmount: 40_000_000n, outerAssetAmount: 60_000_000n }
```

The result is not a reservation. A concurrent deposit can consume capacity before submission.

## Return Value

```ts
type ReturnValue = {
  assetAmount: bigint
  innerAssetAmount: bigint
  outerAssetAmount: bigint
}
```

## Parameters

### assetAmount

- **Type:** `bigint`

### outerVault

- **Type:** `Address`

### recipient

- **Type:** `Address`

Public receiver whose optional receiver cap applies.
